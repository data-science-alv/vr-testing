# Lockdown on Meridian Station

A VR SQL escape room for a database course. It runs entirely in the browser: real Postgres (PGlite) for the queries and WebXR for headsets, with a normal-screen mode for students without one.

- Open the GitHub Pages URL for this repository and enter the access phrase from your instructor.
- Headsets (Meta Quest, Apple Vision Pro): open the same URL in the headset browser and choose **Enter VR headset mode**.
- No headset: choose **Play on this screen**. Drag to look around, click to interact.

Puzzles and expected results are stored encrypted in `data/lab.json`; nothing in this repository contains answers.

Third-party libraries in `vendor/`: three.js (MIT), PGlite (Apache 2.0), jsPDF (MIT).
